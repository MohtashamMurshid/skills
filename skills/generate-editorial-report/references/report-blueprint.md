# Report blueprint

## Map source material to page jobs

| Source material | Best page treatment |
|---|---|
| Central thesis or mandate | Cover + preface |
| 2–4 major findings/projects | Overview + one dossier each |
| Product/interface evidence | Ruled evidence plate |
| Metrics or comparisons | Table, chart, or ledger |
| Timeline | Register or code-native timeline |
| Methods and uncertainty | Field notes |
| People and authorship | Preface portrait or credits |
| Sources and links | Colophon or endnotes |

## Recommended structures

### Compact six-spread report

1. Cover
2. Executive memorandum
3. Key findings
4. Primary dossier
5. Evidence/register
6. Sources and next actions

### Full ten-spread field report

1. Cover
2. Preface
3. Overview
4. Dossier A
5. Dossier B
6. Methods/instruments
7. Public register or chronology
8. Inventory/metrics
9. Field notes and limitations
10. Colophon/sources/contact

### Portfolio report

1. Branded cover
2. Director/author memorandum
3. Current operations
4–6. Project dossiers
7. Public work register
8. Skills/inventory
9. Process notes
10. Contact/colophon

## Writing rules

- Lead with the conclusion or observation, then show evidence.
- Keep most body sections to 60–140 words per spread.
- Use labels and captions to carry factual detail without bloating the main narrative.
- Convert raw bullet lists into ranked findings, ledgers, or inventories.
- Separate facts from interpretation; label estimates and projections.
- Preserve the source’s terminology when changing it would alter meaning.
- Use invented institutional language lightly. It should organize the report, not obscure the subject.

## Fact ledger fields

Track internally:

- `claim`
- `source`
- `source_date`
- `confidence`
- `direct_quote` if any
- `report_section`
- `citation_required`
- `visual_evidence`

If the source conflicts with itself, surface the conflict instead of silently choosing a version.
