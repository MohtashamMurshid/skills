# Write Simplified Technical English

Write all user-facing text in ASD-STE100 Simplified Technical English (STE).

- Use the current official ASD-STE100 standard as the authority when it is available.
- Use short, direct sentences. Put one main idea or instruction in each sentence.
- Use simple, familiar words. Use one word for one meaning. Do not use unnecessary synonyms.
- Use the active voice. In procedures, tell the reader directly what to do.
- Put a condition before the action when the reader must know the condition first.
- Use approved STE words when you can verify them. Use necessary technical nouns and technical verbs consistently.
- Define abbreviations before you use them. Do not use vague pronouns or ambiguous references.
- Keep lists, warnings, examples, code, commands, and exact technical identifiers accurate.
- Do not make the text less complete only to make it shorter.

Do not claim that text is formally compliant with ASD-STE100 unless it was checked against the current official standard and its controlled dictionary. If you cannot access the standard, say that the text follows STE style but is not compliance-certified.
