# Reference analysis

Extract a design system from the supplied images before touching the deck. A successful match reproduces relationships, not isolated decoration.

## Build a visual evidence sheet

Record these dimensions:

1. **Canvas** — aspect ratio, margins, safe area, edge behavior.
2. **Hierarchy** — cover scale, headline size, body density, label treatment.
3. **Composition** — centered versus asymmetric layouts, column counts, dominant shapes, alignment anchors.
4. **Color behavior** — background-to-accent ratio, solid versus gradient, warm/cool sequence, contrast.
5. **Texture and imagery** — grain, blur, cloud, photography, illustration, screenshots, or native geometry.
6. **Recurring motifs** — frames, rules, circles, cards, icons, corner labels, page numbers.
7. **Rhythm** — how dense and sparse slides alternate.
8. **Data language** — tables, bars, circles, diagrams, comparisons, or oversized numbers.

Distinguish invariant rules from one-off content. A single circle is not a system; repeated circles, matching icon geometry, and consistent scale relationships are.

## Transfer the grammar

- Recreate type scale, whitespace, alignment, and composition before tuning color.
- Map the user's content to the reference's slide archetypes; do not force identical text lengths into them.
- Rebuild abstract shapes and exact diagrams natively. Use image generation only when the reference depends on photographic or illustrative texture that code cannot reproduce credibly.
- Reuse the user's logo and brand, not the reference brand.
- Avoid copying distinctive proprietary text, illustrations, or logos.

## Validate with a proof

For a new style, render representative high-risk slides first:

- cover;
- long editorial statement;
- quantitative/data slide;
- process or diagram;
- dense comparison or limitations slide.

Inspect them as a contact sheet and individually. A palette-only match usually becomes obvious at this stage.

When the user asks to see the deck before the style becomes reusable, complete and show the deck first. Record learnings only after approval. Treat approval of the real artifact as stronger evidence than approval of a mood board.

## Common corrections

- **Copy collides at the reference's display scale:** shorten or divide the copy; do not reduce the entire type system.
- **Texture overwhelms readability:** mask it to color fields and keep copy areas white.
- **Vector export becomes huge:** retain the vector/editable source and create a fast-opening rasterized PDF for sharing.
- **Layered shapes fragment in print:** consolidate them into one SVG, canvas, or gradient-backed shape.
- **The deck feels repetitive:** alternate statement, columns, data form, process, example, comparison, and closing compositions.
- **The logo disappears:** move it to a stable high-contrast area or add a restrained backing field.
